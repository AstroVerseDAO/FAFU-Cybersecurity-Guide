# 前言

> 在 GitHub 上读完一个网络空间安全专业的学士学位。

## 为什么写这份指南

福建农林大学计算机与信息学院于 **2020 年** 开始招收网络空间安全专业本科生（专业代码 080911TK，工学，四年制），专业前身是网络工程专业。学院坚持「政校企三位一体」「以赛促学、以赛促教」的人才培养模式，2024 年获批福建省「网络空间安全现代产业学院」省级立项。

但和很多高校一样，**课表只告诉你上什么课，没有人告诉你该怎么学、往哪个方向深挖、课余该补什么**。这门专业覆盖面极广——从密码学、网络攻防，到二进制逆向、取证、隐私保护——单靠课堂很难形成体系。

这份指南想做的事很简单：

1. **把培养方案翻译成学习地图**：每一门课对应什么能力、前置知识是什么、有哪些公认的好资源；
2. **把优秀开源课程按年级和方向整理好**：像 CS 自学指南（PKUFlyingPig 的 cs-self-learning）那样，让每一门课都有清晰的自学路径和资源链接；
3. **把「以赛促学」落到实处**：CTF、信息安全竞赛、安全实验平台，都是课堂之外最有效的成长通道。

## 这本指南不是什么

- 不是课程资料的盗版合集（涉及版权的资料请自行通过正规渠道获取）；
- 不是教务处文件的复读机（培养方案以学校官方最新发布为准，这里的课程地图是辅助理解）；
- 不是保研、就业的承诺书（提供的是信息整理与建议，最终决策请结合自身情况）。

## 如何参与

本项目完全开源（MIT 协议），欢迎所有 FAFU 网安学子、老师与行业朋友共同维护。任何补充、纠错、资源推荐都可以通过 Issue、Pull Request 提交，详见 [贡献指南](贡献指南.md)。

> 最后，网络安全的第一原则是**合法合规**。所有实验请在校内实训平台、CTF 平台或自己搭建的隔离环境中进行，禁止对未授权目标发起任何形式的攻击测试。
