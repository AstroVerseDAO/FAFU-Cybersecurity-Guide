# 操作系统

> 安全的主战场之一。校内对应「操作系统及安全」（第 4 学期）——操作系统本身就是课程的核心安全对象，进程、内存、文件系统处处是攻防的边界。

## 为什么学

- 绝大多数漏洞发生在操作系统与应用程序的边界（栈、堆、内核、权限）；
- 渗透测试、提权、应急响应都要求理解进程、文件权限、系统调用；
- 校内「操作系统及安全」直接考核系统安全机制（见 [操作系统安全](../安全方向/操作系统安全.md)）。

## 核心内容

- 进程与线程、调度
- 内存管理（虚拟内存、页表、地址空间）
- 文件系统与权限模型（Linux 权限、ACL、SELinux/AppArmor 概念）
- 系统调用与用户态/内核态
- 同步与死锁
- 安全相关：缓冲区、权限提升、隔离机制（进阶见操作系统安全页）

## 学习建议

- 把「权限与隔离」作为网安视角的主线：文件权限、SUID、用户态/内核态、容器隔离，逐一看懂；
- 动手：在 Linux 上练习进程管理、软硬链接权限、`strace` 跟踪系统调用；
- 想深入系统安全的同学，大三大四可以做 MIT 6.S081 的实验。
