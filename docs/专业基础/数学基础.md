# 数学基础

> 网安专业的数学主线是「离散 → 数论 → 密码学」。校内课程包括线性代数、概率论与数理统计、离散数学与信息安全数学基础，它们是密码学与协议分析的地基。

## 为什么学

- **信息安全数学基础**（第 3 学期）→ **现代密码学**（第 3 学期）是专业最核心的一条线；
- 数论（同余、群环域、素性测试）直接就是 RSA、ECC 等公钥体制的底层；
- 概率论支撑侧信道分析、随机性安全；线性代数支撑格密码等前沿方向。

## 课程脉络

| 课程 | 校内阶段 | 在网安中的用处 |
| ---- | ---- | ---- |
| 高等数学 / 线性代数 | 大一 | 通用数学素养，后续课程工具 |
| 离散数学 | 大二 | 逻辑、集合、图论——协议与算法的语言 |
| 概率论与数理统计 | 大二 | 安全归约、随机性、统计推断 |
| 信息安全数学基础 | 第 3 学期 | 数论与抽象代数，直通密码学 |

## 学习建议

- 数学课**跟着校内进度走**，别等用到才补——密码学课上现学数论会非常吃力；
- 「信息安全数学基础」务必当主线课认真学，它是后面 [密码学](../安全方向/密码学.md) 与 [安全协议分析](../安全方向/安全协议分析.md) 的入场券；
- 不需要数学系水平，但**同余、群/环/域的基本概念、常用算法（快速幂、扩展欧几里得、中国剩余定理）**要能随手推导。
