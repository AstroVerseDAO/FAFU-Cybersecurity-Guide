# 数据库

> 数据是安全攻防的核心资产。校内对应「数据库原理及安全」（第 4 学期，含课程设计），数据库安全与隐私保护是重要分支。

## 为什么学

- SQL 注入长期位居 Web 漏洞之首，不懂 SQL 就无法理解注入原理；
- 数据泄露、隐私保护、合规审计都围绕数据库展开；
- 校内「数据库原理及安全」将数据库与安全机制合二为一（见 [数据库安全与隐私保护](../安全方向/数据库与隐私保护.md)）。

## 核心内容

- 关系模型与 SQL
- 索引与事务（ACID、隔离级别）
- 数据库设计（ER 模型、范式）
- 安全相关：权限管理、SQL 注入原理、数据加密存储、审计日志

## 学习建议

- 先熟练掌握 SQL（增删改查、联表、子查询），这是 Web 安全的入场券；
- 学完权限模型后，尝试在自建靶场中复现一次 SQL 注入（仅限授权环境）；
- 课程设计认真做，理解「安全」如何贯穿数据生命周期。
