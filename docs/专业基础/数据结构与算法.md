# 数据结构与算法

> 计算机专业的第一门「硬课」。校内第 2 学期开设（含课程设计）。对网安来说，它决定你能读懂漏洞利用代码、写出高效的安全工具。

## 为什么学

- 漏洞分析、恶意代码、协议设计都建立在对数据组织和算法效率的理解之上；
- CTF 中的算法题、密码学中的复杂运算、网络协议的实现都依赖数据结构；
- 它是保研、考研、大厂笔试面试的必考内容。

## 核心内容

- 线性表、栈、队列、串
- 树与二叉树（含 Huffman、堆）
- 图（遍历、最短路径、最小生成树）
- 查找（二分、散列表）与排序（各类复杂度）
- 复杂度分析（大 O 记号）

## 学习建议

- 课程设计（大作业）**认真做**，独立完成一遍胜过刷十遍题；
- 动手实现核心数据结构（栈、队列、树、图、散列表），别只看不写；
- 网安方向不需要竞赛级算法深度，但「会分析复杂度、会选型」是底线要求。
