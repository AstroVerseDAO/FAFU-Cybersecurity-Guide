# 汇编语言

> 离机器最近的语言。校内第 4 学期开设，是逆向工程与二进制安全的直通课——它给你「看穿程序本质」的眼睛。

## 为什么学

- 逆向（[二进制安全与逆向](../安全方向/二进制安全与逆向.md)）的第一步是读懂反汇编；
- 缓冲区溢出、ROP 等利用技术的核心是理解栈与指令流；
- 恶意代码分析（脱壳、混淆还原）离不开汇编层面的解读。

## 核心内容

- 寄存器与寻址方式
- 常用指令（数据传送、算术、逻辑、控制转移、函数调用）
- 栈与函数调用约定（`call`/`ret`、栈帧）
- 与 C 语言对照：看编译器把代码变成什么

## 推荐资源

| 资源 | 类型 | 说明 |
| ---- | ---- | ---- |
| 《汇编语言》（王爽） | 书 | 中文汇编入门经典，配套实验设计极好 |
| 《x86 汇编语言：从实模式到保护模式》 | 书 | 深入 x86 体系的进阶好书 |
| CSAPP 第 3 章（程序的机器级表示） | 书 | 以 C 视角学汇编，网安学生最推荐的路径 |
| [Compiler Explorer](https://godbolt.org/) | 在线工具 | 实时看 C 代码对应的汇编 |

## 学习建议

- 不要求「手写汇编」，要求「读懂汇编」——能对照 C 代码理解反汇编输出即可；
- 重点掌握**栈帧布局与调用约定**（x86-64 下参数如何传、返回值如何回）；
- 学完后立刻接 [逆向工具链](../必学工具/逆向工具链.md) 动手实践，趁热打铁。
