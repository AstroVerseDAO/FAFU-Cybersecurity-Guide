# 程序设计基础

> 网安人的第一门手艺。校内对应「高级程序设计」（第 3 学期，C 语言）等课程。不会写程序，后面所有方向都走不远。

## 为什么学

- **C 语言**：理解内存、指针、栈——这是 [二进制安全与逆向](../安全方向/二进制安全与逆向.md) 的起点；
- **Python**：写利用脚本（pwn）、自动化工具、数据分析的日常语言；
- 看懂代码是渗透、审计、逆向的最基础能力。

## 学习路线

1. **C 语言**为主线（校内课程 + 巩固），把指针、结构体、内存布局学透；
2. **Python** 作为副线，做到「能写脚本」即可（requests、socket、pwntools 起步）；
3. 逐步接触 Shell 脚本、SQL、正则（Web 安全必备）。

## 学习建议

- C 语言学完后，一定写点「窥探内存」的小程序（打印指针、观察栈布局），为逆向打底；
- Python 不求系统学完，用到哪查到哪；
- 大二前的目标：**能独立完成数据结构课程的编程作业，并读懂一段 C 的缓冲区溢出示例代码**（仅在自己靶机上实验）。
