# 计算机组成与系统结构

> 从晶体管到 CPU 再到指令集。理解「机器如何执行程序」，是二进制安全、系统安全的物理前提。

## 为什么学

- 漏洞（缓冲区溢出、ROP 等）本质是程序与硬件/操作系统交互时的边界错误；
- 理解寄存器、栈帧、指令执行流程，才能看懂反汇编与调试器输出；
- 为 [操作系统](操作系统.md)、[汇编语言](汇编语言.md)、[二进制安全与逆向](../安全方向/二进制安全与逆向.md) 提供基础。

## 核心内容

- 数据的表示与运算（补码、浮点）
- 存储体系（寄存器、Cache、内存、磁盘）
- 指令系统与寻址方式
- CPU 结构（控制器、运算器、流水线）
- 输入输出与总线

## 学习建议

- 重点搞清楚**栈与函数调用**（调用约定、栈帧布局）——这是日后看漏洞的必备视角；
- CSAPP 的 3 章（汇编、栈、链接）建议大二假期精读；
- 学完组成原理再看汇编，很多「为什么」会豁然开朗。
