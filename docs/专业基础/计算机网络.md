# 计算机网络

> 一切攻击都发生在网络上。校内课程（计算机网络原理 / 网络安全原理）是攻防方向的必修地基，抓包能力见 [抓包与流量分析](../必学工具/抓包与流量分析.md)。

## 为什么学

- 网络攻防、协议分析、Web 安全全部建立在网络协议之上；
- 理解 TCP/IP 才能看懂扫描、嗅探、中间人、DDoS 等攻击手法的原理；
- 校内「网络安全原理」（第 4 学期）直接承接本课程。

## 核心内容

- 分层模型（应用 / 传输 / 网络 / 链路）
- TCP / UDP 详解（三次握手、四次挥手、可靠传输）
- IP 编址与路由
- DNS、HTTP/HTTPS、DHCP、ARP 等关键协议
- 网络安全基础（加密的传输层实现、防火墙概念）

## 推荐资源

| 资源 | 类型 | 说明 |
| ---- | ---- | ---- |
| 《计算机网络：自顶向下方法》（Kurose & Ross） | 书 | 国际经典教材，配合 Wireshark 实验 |

## 学习建议

- **每学一个协议，就用 Wireshark 抓一次真实流量**——把理论和报文对上号；
- 重点吃透 TCP 状态机与 HTTP 报文结构（Web 安全绕不开）；
- 大二配齐网络基础后，再进入 [网络攻防](../安全方向/网络攻防.md) 方向会非常顺畅。
