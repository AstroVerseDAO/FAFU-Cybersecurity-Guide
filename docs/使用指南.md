# 如何使用这本指南

## 读者对象

| 读者 | 建议阅读路径 |
| ---- | ---- |
| 大一新生 | [前言](index.md) → [专业与课程地图](课程地图.md) → [四年学习规划](学习规划.md) → 「必学工具」 |
| 大二 / 大三 | [课程地图](课程地图.md) → 对应「专业基础」「安全方向」课程页 |
| 高年级 / 准备就业考研 | 「安全方向」深度页 → [CTF 与学科竞赛](竞赛与成长/CTF与竞赛.md) → [考研与深造](竞赛与成长/考研与深造.md) / [就业与认证](竞赛与成长/就业与认证.md) |
| 老师 / 校外朋友 | [贡献指南](贡献指南.md) + 各方向资源页 |

## 页面结构与标注

本指南的页面遵循统一模板（见仓库根目录 `template.md`），每个课程页面包含：

- **为什么学**：这门课在知识体系中的位置；
- **前置知识**：先修要求（可点击跳转到对应页面）；
- **课程内容概览**：核心知识点；
- **推荐资源**：公认好用的教材、公开课、平台；
- **学习建议**：上手路径与常见误区；
- **配套实验**：动手实践入口；
- **校内课程对应**：FAFU 培养方案中的对应课程。

!!! note "关于资源链接"
    推荐资源均为公开、知名的课程或平台。个别需要账号或收费的课程会注明；涉及版权的内容请通过正规渠道获取。

## 阅读顺序建议

**不要试图按目录顺序读完所有页面。** 网安知识体系庞大，正确的姿势是：

1. 先读「课程地图」建立全局认知；
2. 跟着本学期课程走，每门课提前看对应的「前置知识」与「推荐资源」；
3. 学有余力时，按兴趣深入某个「安全方向」，并用 CTF / 实验平台验证所学。

## 约定

- 文中「校内课程」指福建农林大学网络空间安全专业培养方案中的课程，开课学期以教务最新安排为准；
- 所有推荐资源为社区公认口碑较好的选择，不构成对特定课程的官方认可。
