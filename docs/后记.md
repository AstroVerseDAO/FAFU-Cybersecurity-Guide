# 后记

> 写到这里，这份指南的第一版骨架就算立起来了。

## 想清楚的三件事

**第一，指南是「地图」，不是「捷径」。** 地图只告诉你哪里有路，路要自己走。每一个方向背后都是几百小时的练习——这正是它值得的原因。

**第二，网安人的三件套：好奇心、动手、守法。** 好奇心驱动你深挖，动手让知识变成能力，守法让你走得更远而不是更快出事。

**第三，这是一份持续生长的文档。** 第一版一定有不完善的地方：课程信息会变、资源链接会失效、新方向会出现。它需要一届又一届 FAFU 学子的接力维护，才配得上「指南」二字。

## 给后来者的话

如果你是大一新生：恭喜你，选了一个难但值得的专业。别怕基础差，这个专业最公平的地方在于——**刷过的题、写过的 Writeup、打过的比赛，都不会骗你**。

如果你是高年级同学：希望这份指南的「以赛促学」部分能帮你找到组织，把经验沉淀成页面，传给下一届。

如果你是社会上的安全从业者：欢迎通过 Issue 指正与补充，让母校的后来者看到行业真实的模样。
