# 好书推荐

> 精选网安学习各阶段的中文/英文好书。读书贵精不贵多——先读完手头的，再买下一本。

## 入门启蒙

| 书名 | 说明 |
| ---- | ---- |
| 《图解密码技术》（结城浩） | 密码学零门槛入门，图解友好 |
| 《白帽子讲 Web 安全》（吴翰清） | Web 安全世界观 + 实战入门 |
| 《网络攻防技术与实践》（诸葛建伟） | 攻防体系化入门，与校内课程契合 |

## 专业进阶

| 书名 | 说明 |
| ---- | ---- |
| 《深入理解计算机系统》（CSAPP） | 程序员视角的计算机系统，网安必读 |
| 《操作系统导论》（OSTEP） | 操作系统教学经典，官网免费 |
| 《计算机网络：自顶向下方法》 | 网络经典教材 |
| 《汇编语言》（王爽） | 汇编入门经典 |
| 《加密与解密》（第 4 版） | 逆向工程中文权威 |
| 《0day 安全：软件漏洞分析技术》 | 漏洞分析与利用入门 |
| 《恶意代码分析实战》 | 恶意代码分析圣经 |
| 《深入浅出密码学》（Christof Paar） | 密码学理论与实现 |

## 数学与理论

| 书名 | 说明 |
| ---- | ---- |
| 《信息安全数学基础》 | 校内课程主线教材 |
| 《离散数学及其应用》（Rosen） | 离散数学经典 |

## 阅读建议

- **少而精**：每个方向选 1-2 本从头读完，胜过收藏十本只翻目录；
- **书 + 实验**：读完章节立刻动手验证（靶场、代码实现），书才真正变成能力；
- 英文能力是网安学习的隐形门槛，尽早开始读英文文档与英文教材。
