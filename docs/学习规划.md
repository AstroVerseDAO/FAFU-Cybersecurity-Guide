# 四年学习规划

> 这是一份**参考性**的四年路线图，基于培养方案课程顺序与网安知识体系的内在依赖整理。请结合自己的节奏调整，重点是理解「为什么要按这个顺序学」。

## 大一：地基期（编程 + 工具 + 数学）

**目标**：成为「会用工具写程序」的人。

- **编程**：以 C 语言入门（对应 FAFU「高级程序设计」），课余补充 Python；
- **工具**：Linux 与命令行、Git/GitHub、Vim——详见 [必学工具](必学工具/Linux.md)；
- **数学**：高等数学、线性代数认真学，它们是后续「信息安全数学基础」的地基；
- **认知**：读完 [网络空间安全导论](安全方向/网络空间安全导论.md)（校内第 2 学期开设），了解这个专业到底做什么；
- **兴趣**：逛一圈 [CTF 平台与资源](必学工具/CTF平台与资源.md)，看两道入门题的题解，知道「攻防长什么样」。

??? note "大一常见误区"
    - 只刷题不读文档、不用 Linux；
    - 把 C 语言当成「考完就扔」的课——它是后续汇编、逆向、操作系统安全的地基。

## 大二：筑基期（专业基础 + 安全入门）

**目标**：建立计算机系统全景认知，摸到安全的门。

- **专业基础**：数据结构与算法（第 2 学期）、汇编语言（第 4 学期）、计算机网络、操作系统及安全——这四门是网安的核心地基；
- **数学转安全**：信息安全数学基础（第 3 学期）→ 现代密码学（第 3 学期）；
- **安全起步**：网络安全原理（第 4 学期）、安全协议分析（第 4 学期）、数据库原理及安全（第 4 学期）；
- **动手**：开始系统刷 CTF 入门题（Web + Crypto + Misc 起步），把 [安全实验平台](实验与实践/安全实验平台.md) 用起来。

## 大三：主攻期（方向成型）

**目标**：选定 1-2 个主攻方向，达到「能独立完成小项目/比赛题」的水平。

- **攻防方向**：网络攻防技术（第 6 学期）、Web 安全、防火墙与入侵检测；
- **逆向方向**：软件安全（第 5 学期）、二进制安全与逆向，配合 pwn/Reverse CTF 题；
- **数据与隐私**：数据库安全、大数据安全与隐私保护、数字取证（第 5 学期）、网络舆情安全技术；
- **前沿拓展**：物联网安全、云安全、AI 安全（按兴趣选修）；
- **合规底线**：网络安全法律与伦理（第 5 学期）——务必学，安全人先学法；
- **竞赛实战**：组队参加全国大学生信息安全竞赛、主流 CTF，详见 [CTF 与学科竞赛](竞赛与成长/CTF与竞赛.md)。

## 大四：综合期（产出 + 出路）

**目标**：形成可展示的成果，明确毕业去向。

- **毕业设计**：结合主攻方向选题，做出完整的安全项目（漏洞分析、安全工具、检测系统等）；
- **实习**：安全公司、政企安全部门的实习经历是就业的重要筹码；
- **出路规划**：考研/保研（[考研与深造](竞赛与成长/考研与深造.md)）还是就业（[就业与认证](竞赛与成长/就业与认证.md)），大四上学期前想清楚并做准备。

## 一张图总结

```
大一   编程 C/Python · Linux · Git · 数学            → 会用工具
  ↓
大二   数据结构 · 组成原理 · 操作系统 · 网络          → 懂系统
       信息安全数学 · 密码学 · 安全导论
  ↓
大三   攻防 · Web安全 · 逆向 · 取证 · 隐私            → 有方向
       CTF + 实验平台 + 竞赛
  ↓
大四   毕业设计 · 实习 · 考研/就业                    → 有产出
```

!!! warning "最重要的一句话"
    这份规划**可以跳过、可以加速、可以重排**，但有两件事没有替代品：**动手实验**和**合法合规**。所有练习都在授权环境（校内实训平台、CTF 平台、自建靶场）中进行。
