# 二进制安全与逆向

> 网安最「硬核」的方向之一。校内对应「软件安全」（第 5 学期，核心课）、「软件逆向工程」以及汇编语言课程。漏洞挖掘、病毒分析、CTF Pwn/Reverse 都在这里。

## 为什么学

- 真正理解漏洞（缓冲区溢出、UAF、ROP）必须回到二进制层面；
- 恶意代码分析（[恶意代码分析](恶意代码分析.md)）的前提是逆向能力；
- 大厂安全研究员、漏洞挖掘岗位的核心技能。

## 前置知识

- [汇编语言](../专业基础/汇编语言.md)、[计算机组成与系统结构](../专业基础/计算机组成与系统结构.md)
- [程序设计基础](../专业基础/程序设计基础.md)（C 语言、指针）
- 工具见 [逆向工具链](../必学工具/逆向工具链.md)

## 核心内容

- 逆向基础：反汇编、反编译、调试、脱壳
- 漏洞原理：栈溢出、堆溢出、UAF、整数溢出、格式化字符串
- 利用技术：ROP、ret2libc、Shellcode
- 防护与绕过：NX/DEP、ASLR、PIE、Canary、SELinux/沙箱概念
- 漏洞挖掘入门：Fuzzing 概念（AFL 等）

## 学习建议

- **顺序**：汇编 → 栈原理 → 第一个缓冲区溢出 → ROP → 堆 → 防护绕过；
- 大量练习：BUUCTF 的 Pwn/Reverse 入门题带题解，pwn.college 有自动评分；
- 校内「软件安全」课程认真跟，配套实验反复做；
- 逆向讲究手感，保持每周几题的频率比突击有效得多。
