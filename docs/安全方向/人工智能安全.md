# 人工智能安全

> 前沿交叉方向。校内相关课程为「人工智能及安全」（方向课）。AI 既是被攻击的对象（对抗样本、模型窃取），也是安全的武器（智能检测、自动化攻防）。

## 为什么学

- AI 已深度嵌入安全检测（恶意代码检测、入侵检测、内容安全）——学院在机器学习与安全结合方向有师资积累；
- 大模型时代，提示注入、模型安全、数据投毒成为新威胁维度；
- 这是一个快速扩张的蓝海方向，交叉背景（安全 + AI）稀缺且抢手。

## 前置知识

- [程序设计基础](../专业基础/程序设计基础.md)（Python）
- 机器学习基础概念（建议配合数学基础中的概率论）

## 核心内容

- AI 用于安全：恶意样本检测、异常检测、日志分析、NLP 内容安全
- 安全对抗 AI：对抗样本、数据投毒、模型窃取/反演
- 大模型安全：提示注入、越狱、幻觉风险、AI 内容滥用治理
- 自动化：AI 辅助漏洞挖掘、代码审计、智能渗透
