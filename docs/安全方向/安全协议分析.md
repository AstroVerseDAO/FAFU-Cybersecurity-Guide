# 安全协议分析

> 校内第 4 学期核心课。协议是「安全机制的组合规则」，协议漏洞往往比算法漏洞更致命——算法没问题，用错了也能被攻破。

## 为什么学

- TLS、SSH、IPSec、认证协议（Kerberos 等）是所有安全系统的骨架；
- 安全协议是 [密码学](密码学.md) 的实战延伸：把密码原语组合成可信的通信过程；
- 协议逻辑漏洞（重放、中间人、降级攻击）是研究级安全的重要领域。

## 前置知识

- [密码学](密码学.md)：加密、签名、密钥交换
- [计算机网络](../专业基础/计算机网络.md)：TCP、TLS 在分层中的位置
- 抓包工具：[抓包与流量分析](../必学工具/抓包与流量分析.md)

## 核心内容

- 协议安全目标：机密性、完整性、认证、不可否认
- 常见协议族：TLS/HTTPS、IPSec、SSH、Kerberos、VPN
- 典型攻击：重放攻击、反射攻击、中间人、会话劫持、降级攻击
- 协议设计原则与形式化分析概念（Dolev-Yao 模型等）

## 推荐资源

| 资源 | 类型 | 说明 |
| ---- | ---- | ---- |
| 《网络安全协议：原理、结构与应用》（寇晓蕤等） | 教材 | 中文协议分析经典教材 |
| RFC 文档（TLS 1.3 等） | 文档 | 权威一手资料（[rfc-editor.org](https://www.rfc-editor.org/)） |
| Wireshark 抓 TLS 流量分析 | 实操 | 观察握手过程（ClientHello→密钥交换→Application Data） |

## 学习建议

- 用 Wireshark 完整抓一次 HTTPS 握手，对照 RFC 把每个报文看懂——比读十遍书都有效；
- 思考题：为什么需要「随机数 + 时间戳」防重放？为什么证书体系可以防中间人？
- 与 [网络攻防](网络攻防.md) 配合：很多攻击（如 SSL 剥离、会话固定）本质是协议层面问题。
