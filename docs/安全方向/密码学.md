# 密码学

> 安全的数学基石。校内对应「现代密码学」（第 3 学期，核心课）与「信息安全数学基础」（第 3 学期），是 FAFU 网安专业最鲜明的主线之一。

## 为什么学

- 加密、签名、哈希是所有安全机制（TLS、VPN、区块链、数据保护）的底层；
- CTF Crypto 方向、协议分析、数字取证都离不开密码学思维；
- 密码学是「可证明安全」的学科，训练严谨的数学化思考方式。

## 前置知识

- [数学基础](../专业基础/数学基础.md)：同余、群环域、快速幂、扩展欧几里得

## 核心内容

- 古典密码与代换/置换
- 对称密码：DES / AES、分组模式（CBC、CTR）、流密码
- 非对称密码：RSA、Diffie-Hellman、ECC 原理
- 哈希函数与消息认证（MD5/SHA 系列、HMAC）
- 数字签名与公钥基础设施（PKI/Certificate）
- 攻击思路：暴力、频率分析、数学攻击（分解、离散对数）、侧信道概念

## 学习建议

- **数学优先**：先吃透 [信息安全数学基础]，再学公钥密码会轻松很多；
- 每学一种算法，写代码实现一遍（RSA 加解密、AES 调用），并尝试用脚本「攻破」玩具版算法；
- CTF Crypto 入门：从古典密码 + 简单数论题开始，逐步接触 RSA 常见攻击（低指数、共模、Wiener 等）——这些题目是对课堂知识的极好强化。
