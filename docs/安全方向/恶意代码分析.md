# 恶意代码分析

> 校内对应「计算机病毒原理与防范」（第 4 学期，核心课）。恶意代码分析是安全运营、应急响应、威胁情报的核心能力。

## 为什么学

- 病毒、木马、勒索软件是安全事件的直接元凶，分析师必须「解剖」它们；
- 应急响应岗位的核心工作：发现样本 → 分析行为 → 清除与溯源；
- 学院在计算机病毒、信息内容安全方向有深厚师资积累（王长缨教授等）。

- [逆向工具链](../必学工具/逆向工具链.md)、[二进制安全与逆向](二进制安全与逆向.md)

## 核心内容

- 恶意代码分类：病毒、蠕虫、木马、勒索、间谍、Rootkit
- 分析流程：静态分析 → 动态分析 → 行为分析 → 报告
- 静态手段：查壳、字符串、导入表、反汇编（对应课程「病毒原理」）
- 动态手段：沙箱运行、网络行为监控（抓包）、进程/文件行为监控
- 免杀与检测对抗概念：加壳、混淆、反调试

## 学习建议

- **安全第一**：分析样本必须用隔离虚拟机（[虚拟机与 Kali](../必学工具/虚拟机与Kali.md)），断网或模拟网络，严禁在真机运行；
- 从「分析一个已知样本」开始：下载公开样本集（如 Malware-Traffic-Analysis），写分析报告；
- 与 [数字取证](数字取证.md) 配合，形成「样本 → 行为 → 溯源」完整链条。
