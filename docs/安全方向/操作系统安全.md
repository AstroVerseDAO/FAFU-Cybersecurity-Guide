# 操作系统安全

> 校内核心课「操作系统及安全」（第 4 学期）。操作系统是所有安全机制的宿主，理解系统安全 = 理解攻击的落点。

## 为什么学

- 提权、持久化、沙箱逃逸等高级攻击都发生在 OS 层面；
- 安全运维、应急响应要懂系统加固（账号、权限、服务、日志）；
- 校内课程直接考核系统安全机制，是专业核心能力之一。

## 前置知识

- [操作系统](../专业基础/操作系统.md)：进程、内存、文件系统、内核态/用户态

## 核心内容

- 身份认证与访问控制（DAC、MAC、最小权限）
- Linux 权限体系：文件权限、SUID/SGID、sudo 策略、Capabilities 概念
- 安全机制：ASLR、NX、Canary、PIE（与 [二进制安全与逆向](二进制安全与逆向.md) 呼应）
- 内核安全概念：系统调用、内核模块、提权原理
- 系统加固：账号策略、服务最小化、日志审计、基线检查
- Windows 安全基础：注册表、服务、域控概念（拓展）

## 学习建议

- 在 Linux 虚拟机里把权限体系「玩明白」：建用户、改权限、做 SUID 实验；
- 尝试复现一次经典提权（如利用 SUID 程序或内核漏洞——仅在自建靶机）；
- 结合 [网络攻防](网络攻防.md)：攻防演练中「横向移动 + 提权」是核心链条。
