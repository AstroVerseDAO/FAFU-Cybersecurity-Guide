# 数字取证与舆情安全

> 校内对应「计算机取证」（第 5 学期，核心课）与「网络舆情安全技术」（主干课程）。取证是从「事件发生」到「真相还原」的技术链。

## 为什么学

- 数字取证是安全事件处置（应急响应）的收尾环节，也是司法与执法场景的核心需求；
- 网络舆情安全是 FAFU 专业的特色方向之一（学院有网络舆情监测系统等实验设备）；
- CTF Misc 方向大量考察取证技能（文件分析、隐写、流量取证）。

## 核心内容

- 取证流程：保全 → 镜像 → 分析 → 报告（证据链意识）
- 磁盘与文件取证：文件系统、删除文件恢复、日志分析
- 内存取证（Volatility 等）
- 网络取证：流量还原、日志关联
- 隐写术与隐写分析（图片、音频、流量隐写）——CTF Misc 高频考点
- 网络舆情：舆情监测、内容安全、溯源（FAFU 特色课程）

## 学习建议

- 建立「证据链」思维：取证的第一步是保全与记录，不是分析；
- 多刷 Misc 题：隐写（LSB、文件合并、图片属性）是性价比极高的入门练习；
- 校内课程设计认真做，取证报告的规范性本身就是加分项。
