# 数据库安全与隐私保护

> 校内对应「数据库原理及安全」（第 4 学期，核心课，含课程设计）与「大数据安全与隐私保护」（主干课程）。数据是数字时代的核心资产，保护数据 = 保护一切。

## 为什么学

- 数据泄露是近年安全事件的重灾区，合规要求（等保、数据安全法）持续收紧；
- 数据库安全（权限、审计、加密）是安全运维的日常工作；
- 大数据时代，隐私保护技术（脱敏、差分隐私、加密计算）成为新兴热门方向。

## 前置知识

- [数据库](../专业基础/数据库.md)：SQL、事务、权限模型

## 核心内容

- 数据库安全机制：用户权限、视图、审计日志、备份恢复
- SQL 注入的防护（见 [Web 安全](Web安全.md)）
- 数据加密：透明加密（TDE）、字段级加密
- 隐私保护技术：数据脱敏、匿名化、差分隐私概念、多方安全计算/同态加密概念
- 大数据安全：数据生命周期管理、Hadoop/数据湖安全基线

## 学习建议

- 把「权限最小化 + 审计」刻进习惯：任何数据库设计先想权限矩阵；
- 课程设计阶段主动加入「安全设计」元素（加密字段、审计表、脱敏接口）；
- 关注《数据安全法》《个人信息保护法》对技术方案的影响（见 [法律伦理与合规](法律伦理与合规.md)）。
