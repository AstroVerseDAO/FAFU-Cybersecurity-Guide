# 法律伦理与合规

> 校内第 5 学期开设核心课「网络安全法律与伦理」。安全人最重要的不是技术上限，而是行为边界——这门课决定你能走多远。

## 为什么学

- 《网络安全法》《数据安全法》《个人信息保护法》构建了中国的网络安全法律体系；
- 渗透测试、取证、数据处理都必须在法律与授权框架内进行；
- 合规（等保测评、数据合规）本身就是一个专业岗位方向。

## 核心内容

- 网络安全法律体系：网络安全法、数据安全法、个人信息保护法、刑法相关条款（非法侵入、破坏计算机信息系统罪等）
- 授权与边界：渗透测试授权书、漏洞披露规范（漏洞报告与应急响应）
- 伦理与职业操守：安全研究人员的责任、漏洞奖励计划（SRC）
- 等保与合规基础：等级保护制度、数据分类分级概念

## 学习建议

- **把合规变成肌肉记忆**：练靶只进授权平台（校内实训、CTF、自建靶场），不碰未授权目标；
- 了解漏洞报告的正确姿势：通过 SRC 平台（各大厂商安全应急响应中心）提交，而非公开炫耀；
- 从事取证方向的同学，认真学习证据保全与司法鉴定规范。
