# 物联网与云安全

> 新兴安全主战场。校内师资覆盖「物联网安全」「云计算与虚拟化安全」（舒兆港、陈日清等老师方向），契合 FAFU 农林信息化与智慧农业的应用场景。

## 为什么学

- 物联网设备（摄像头、传感器、智慧农业终端）普遍「裸奔」，是攻击面扩张最快的领域；
- 云计算成为企业基础设施，云安全（虚拟化隔离、容器安全、IAM）需求爆发；
- 农林特色：智慧林业、农业物联网的安全防护是 FAFU 的差异化优势方向。

## 前置知识

- [计算机网络](../专业基础/计算机网络.md)、[操作系统](../专业基础/操作系统.md)
- [Docker](../必学工具/Docker.md)（云原生/容器安全基础）

## 核心内容

- 物联网安全：设备固件分析、通信协议（MQTT/CoAP）、传感器安全、OTA 安全
- 云安全：虚拟化与 Hypervisor、容器（Docker/K8s）安全、云 IAM 与身份管理
- 典型风险：固件提取、协议重放、容器逃逸概念、错误配置（错误暴露的 S3/数据库）
- 防护思路：设备认证、安全更新、网络分段、最小权限

## 学习建议

- 结合农林场景选题（智慧农业设备、林业监测网络），既是特色也是毕设/竞赛好方向；
- 云安全学习路径：Linux → Docker → K8s 基础 → 云架构 → 云安全基线（CIS Benchmarks）；
- 关注学院实验室设备（物联网安全智能监控平台等），主动申请参与项目。
