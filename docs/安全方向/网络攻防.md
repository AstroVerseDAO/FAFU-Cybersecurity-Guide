# 网络攻防

> 网安专业的「实战课」。校内对应「网络安全原理」（第 4 学期）、「网络攻防技术」（第 6 学期，核心课），并涉及防火墙原理与技术、入侵检测技术等。

## 为什么学

- 攻防是理解安全的最佳途径：不知道攻击怎么做，就无法真正防守；
- 渗透测试、安全运维、应急响应岗位的核心技能；
- 校内实训与学科竞赛的主战场。

## 核心内容（攻击视角）

- 渗透测试流程：信息收集 → 漏洞发现 → 利用 → 提权 → 后渗透 → 报告
- 常用技术：端口扫描、漏洞扫描、密码爆破、漏洞利用（Metasploit）、中间人攻击
- Web 攻击入口见 [Web 安全](Web安全.md)
- 常见防护机制：防火墙、IDS/IPS、WAF、安全基线（见 [操作系统安全](操作系统安全.md)）

## 学习建议

- **流程大于炫技**：先完整走一遍渗透测试标准流程，输出规范报告（这是岗位要求的核心能力）；
- 靶场练习优先：Metasploitable 2、DVWA、VulnHub 等（见 [安全实验平台](../实验与实践/安全实验平台.md)）；
- 务必在**授权环境**练习；攻防的本质是责任与边界，违规操作后果严重。
