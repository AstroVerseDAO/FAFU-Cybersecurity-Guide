# 网络空间安全导论

> 校内第 2 学期开设（16 学时）。这门课是你对专业的第一次系统认知——它回答「网络空间安全到底是什么、学什么、怎么发展」。

## 为什么学

- 建立专业全景：安全不止「黑客攻防」，还有密码、协议、系统、数据、合规；
- 了解学科脉络与国家战略背景（网络空间安全一级学科、相关法律体系）；
- 帮助你在后续选方向（攻防 / 逆向 / 取证 / 隐私 / 云物联安全）前形成判断。

## 核心内容（建议）

- 网络空间安全的概念与范畴
- 安全三要素（CIA：机密性、完整性、可用性）
- 攻击面与常见威胁分类（恶意代码、网络攻击、社会工程等）
- 学科方向地图与职业方向
- 安全法律与伦理入门

## 学习建议

- 这门课是「地图课」，重点是建立认知框架，不必追求技术深度；
- 边学边逛 [CTF 平台与资源](../必学工具/CTF平台与资源.md)，把「抽象的概念」和「具体的题」对应起来；
- 主动了解校内实验室、竞赛队（学院以赛促学氛围浓厚），尽早找到组织。
