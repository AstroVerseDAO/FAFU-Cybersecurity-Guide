# 安全实验平台

> 网安学习 70% 靠动手。这里汇总校内外的实验环境与靶场，全部为**授权环境**，放心练习。

## 校内平台

- 网络安全虚拟仿真实验系统（网络空间安全创新实训平台）
- 信息安全实训平台（含 Web、密码、取证等模块）
- 网络舆情监测系统、物联网安全智能监控平台
- 以上设备均依托学院实验中心，课程实训中使用

## 自建靶场（推荐本地搭建）

| 靶场 | 说明 |
| ---- | ---- |
| DVWA（[github.com/digininja/DVWA](https://github.com/digininja/DVWA)） | Web 漏洞靶场，入门首选，一条 Docker 命令启动 |
| pikachu | 中文 Web 漏洞靶场，适合新手 |
| WebGoat（[github.com/WebGoat/WebGoat](https://github.com/WebGoat/WebGoat)） | OWASP 官方教学靶场 |
| Metasploitable 2 | 漏洞主机镜像，配合 [虚拟机与 Kali](../必学工具/虚拟机与Kali.md) 使用 |
| VulnHub（[vulnhub.com](https://www.vulnhub.com/)） | 各种难度靶机镜像，进阶练习 |

## 在线平台

| 平台 | 说明 |
| ---- | ---- |
| TryHackMe（[tryhackme.com](https://tryhackme.com/)） | 引导式学习，新手友好 |
| HackTheBox（[hackthebox.com](https://www.hackthebox.com/)） | 进阶靶机，社区活跃 |
| pwn.college（[pwn.college](https://pwn.college/)） | 二进制/利用方向系统课程 + 自动评测 |
| PortSwigger Academy（[portswigger.net/web-security](https://portswigger.net/web-security)） | Web 安全官方免费课程 + 实验 |
| OverTheWire（[overthewire.org](https://overthewire.org/)） | 命令行/协议闯关（Bandit 等） |

## 使用规范

::: warning
  - 所有平台均为授权环境，练习产生的数据（payload、样本）不得用于真实目标；
  - 恶意代码样本只在隔离虚拟机分析（见 [恶意代码分析](../安全方向/恶意代码分析.md)）；
  - 校内平台遵守实验室管理规定。
:::
