# 课程设计与实训

> 实践性教学环节是 FAFU 网安专业的重点：课程设计、综合实训、毕业设计层层递进，把「学过」变成「会做」。

## 课程设计（课程内大作业）

培养方案中的主要课程设计环节（以教务安排为准）：

- **数据结构（课程设计）**：独立完成一个完整项目（如图书管理系统、校园导航等），重点训练编码与工程规范；
- **数据库安全（课程设计）**：带安全设计（权限矩阵、审计、加密字段）的数据库应用；
- **操作系统安全（课程设计）**：系统加固或安全机制实验。

**怎么做才值**：不要只求「通过」，把课程设计当成作品来做——写好 README、画好架构图、留好 Git 提交记录，它就是简历上的项目。

## 综合实训

- 校内实训依托**网络安全虚拟仿真实验系统、信息安全实训平台、网络舆情监测系统**等设备（学院投资建设）；
- 形式多为「攻防演练 / 靶场通关 / 综合项目」，与 [网络攻防](../安全方向/网络攻防.md) 课程呼应。

## 毕业设计

- 大四完成，选题建议结合主攻方向：漏洞分析、安全工具、检测系统、隐私保护方案、智慧农林安全应用等；
- 提前（大三下）确定方向并准备素材，避免大四仓促。

## 实训规范提醒

- 实训均在校内授权平台进行，遵守实验室安全规范；
- 涉及真实数据的项目注意脱敏与合规（见 [法律伦理与合规](../安全方向/法律伦理与合规.md)）。
