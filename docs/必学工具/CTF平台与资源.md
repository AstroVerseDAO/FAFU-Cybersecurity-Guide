# CTF 平台与资源

> CTF（Capture The Flag，夺旗赛）是网安学习的「游戏化课堂」，也是 FAFU 学院「以赛促学」特色的核心载体。这里汇总常用平台与入门资源。

## 常用在线平台

| 平台 | 地址 | 说明 |
| ---- | ---- | ---- |
| BUUCTF | https://buuoj.cn/ | 国内最常用的练题平台，题目全、题解多，入门首选 |
| 攻防世界 | https://adworld.xctf.org.cn/ | XCTF 官方平台，含历年真题 |
| picoCTF | https://picoctf.org/ | CMU 主办，面向初学者的经典平台，题目友好 |
| XCTF 社区 | https://xctf.org.cn/ | 国内 CTF 赛事社区 |
| CTFtime | https://ctftime.org/ | 全球赛事日历与积分榜 |

## 入门建议

1. **先定方向**：把每个方向的入门题各做几道，找到最感兴趣的一两个；
2. **以题带学**：不会什么就学什么，看完题解一定自己重做一遍；
3. **写 Writeup**：每道题写解题记录（放 GitHub），既是复习也是履历；
4. **组队参赛**：关注 CTFtime 上的线上赛，和同学组队打几场，体验真实节奏（详见 [CTF 与学科竞赛](../竞赛与成长/CTF与竞赛.md)）。

::: tip
  校内的「以赛促学」氛围浓厚（学院在信息安全类竞赛中获奖众多）。主动找学长学姐组队、问老师要赛题资源，是成长最快的捷径。
:::
