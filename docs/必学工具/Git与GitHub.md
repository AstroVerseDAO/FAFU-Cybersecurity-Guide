# Git 与 GitHub

> 程序员世界的「保存」与「协作」。本指南本身就是托管在 GitHub 上的开源项目，参与贡献的第一步就是学会 Git。

## 为什么学

- 所有课程作业、项目、论文代码都值得用 Git 管理（再也不用「最终版 v12」）；
- 开源安全项目（Kali 工具、漏洞库、CTF 题解）几乎都在 GitHub 上，这是你学习与展示的主阵地；
- 向本仓库提交 Issue / PR 也需要它。

## 核心概念

- **仓库（Repository）**：项目容器
- **提交（Commit）**：一次版本快照
- **分支（Branch）**：并行开发线（如 `main`）
- **推送 / 拉取（Push / Pull）**：本地与远程同步
- **合并（Merge）与拉取请求（PR）**：协作合并代码

## 学习建议

- 本周内就把第一个仓库建起来（哪怕是笔记），日常提交；
- 学会看 `git log` 和 `git diff`，这是排查问题的基础；
- 用 GitHub Pages 部署你的第一个个人主页，顺便理解 [本站的部署方式](../贡献指南.md)。
