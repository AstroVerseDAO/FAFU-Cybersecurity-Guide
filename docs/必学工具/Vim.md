# Vim

> 终端里的编辑器之王。在服务器上改配置、在靶场里快速编辑、在无图形界面环境工作时，Vim 是最可靠的伙伴。

## 为什么学

- SSH 到远程服务器 / 靶机后，常用的编辑工具就是 Vim；
- 习惯 Vim 后编辑效率极高（但需要刻意练习初始阶段）。

## 入门路径

1. 终端输入 `vimtutor`，官方互动教程，约 30 分钟过一遍；
2. 掌握模式概念：**普通模式（Normal）/ 插入模式（Insert）/ 命令行模式**；
3. 记住最常用的几个操作即可开始，别追求「键位全背」。

## 核心操作速查

- `i` 插入、`Esc` 回到普通模式
- `:w` 保存、`:q` 退出、`:wq` 保存退出、`:q!` 放弃修改退出
- `dd` 删行、`yy` 复制行、`p` 粘贴
- `/keyword` 搜索、`n` 下一个匹配
- `gg` 文件开头、`G` 文件末尾

## 学习建议

- 先做到「能在 Vim 里改完一个文件」再谈效率；
- 日常编辑不必强求 Vim，但至少要「不害怕」它——服务器上它常常是唯一选择。
