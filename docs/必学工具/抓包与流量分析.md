# 抓包与流量分析

> 网络安全的「显微镜」。看懂数据包，才能理解攻击如何发生、协议如何被利用，也是数字取证与应急响应的基本功。

## 为什么学

- 校内「网络安全原理」「网络攻防技术」课程的核心实验就是抓包分析；
- 排查问题（连接异常、恶意流量、漏洞验证）离不开流量视角；
- 取证方向（数字取证、网络舆情）的日常就是分析流量与日志。

## 工具选择

- **Wireshark**：图形化抓包分析，功能最全，[官网下载](https://www.wireshark.org/)；
- **tcpdump**：命令行抓包，服务器上最常用（`sudo tcpdump -i eth0 -w cap.pcap`）；
- **TShark**：Wireshark 的命令行版本，适合脚本化分析。

## 入门路径

1. 会抓包：选定网卡 → 开始抓取 → 停止保存（`.pcap` 文件）；
2. 会看包：理解**分层模型**（以太网 / IP / TCP / HTTP 等），看懂三次握手、HTTP 请求响应；
3. 会用过滤器：显示过滤器（`http`、`tcp.port == 443`、`ip.src == x.x.x.x`）是效率关键；
4. 会追踪流：右键「Follow TCP Stream」还原一次完整会话。

## 学习建议

- 配合 [计算机网络](../专业基础/计算机网络.md) 一起学，抓包是对网络理论最好的验证；
- 用 Wireshark 复现课程中学过的每个协议（DHCP、DNS、HTTP、HTTPS…）；
- CTF 中 Misc 方向经常考流量分析，练好后一举两得。
