# 逆向工具链

> 读懂程序「真正的逻辑」。逆向是软件安全、恶意代码分析的基石，工具链则是逆向工程师的双手。

## 为什么学

- 校内「软件安全」「计算机病毒原理与防范」课程直接依赖逆向能力；
- CTF 的 Reverse / Pwn 方向、漏洞挖掘、病毒分析全部建立在逆向基础上。

## 工具链组成

| 环节 | 工具 | 说明 |
| ---- | ---- | ---- |
| 静态分析 | Ghidra / IDA | 反汇编 + 反编译。Ghidra 免费开源（NSA 出品），IDA Free 版可入门 |
| 动态调试 | GDB（Linux）/ x64dbg（Windows）/ LLDB | 断点、单步、内存查看 |
| 动态插桩 | Frida | 运行时 hook 与调用跟踪，移动安全与脱壳常用 |
| 二进制操作 | pwntools（Python）、objdump、readelf | 解析 ELF，编写利用脚本 |
| 字符串/熵分析 | strings、file、binwalk、Detect It Easy | 快速侦察文件类型与内容 |

## 入门路径

1. **汇编语言**先行（校内第 4 学期课程），能读懂常见指令（`mov` `push` `call` `jmp`…）；
2. 用 Ghidra 打开一个简单程序（如自己写的 C 程序），对照反编译结果理解逻辑；
3. 用 GDB 对程序下断点、看寄存器与栈；
4. 刷 CTF Reverse 入门题（BUUCTF 等平台有大量带题解的题目）。

## 学习建议

- 先静态后动态：先看懂代码再上调试器；
- 逆向非常吃「量」，保持每周几道题的手感；
- 与 [二进制安全与逆向](../安全方向/二进制安全与逆向.md)、[恶意代码分析](../安全方向/恶意代码分析.md) 课程页配合学习。
