# CTF 与学科竞赛

> FAFU 计算机与信息学院坚持「以赛促学、以赛促教」，在信息安全类竞赛中成果丰硕。竞赛是网安学生成长最快的通道之一。

## 为什么要打比赛

- **以赛促学**：CTF 是「用问题驱动学习」，比被动听课高效得多；
- **履历价值**：信息安全类竞赛奖项在保研、求职中的含金量高；
- **团队与资源**：通过比赛认识队友、学长学姐和指导老师，获得长期成长资源。

## 赛事地图

| 类别 | 代表赛事 | 说明 |
| ---- | ---- | ---- |
| 国家级学科竞赛 | 全国大学生信息安全竞赛 | 网安领域权威赛事，学院重点参与 |
| 网络安全专项赛 | 网鼎杯、强网杯、蓝帽杯等 | 由政府部门/企业主办，社会认可度高 |
| 国际/线上 CTF | DEF CON CTF、各类 XCTF 联赛 | 全球顶级赛事（CTFtime 查看日历） |
| 高校联赛 | 各省市高校网安联赛 | 校内/省内练兵机会 |

## 组队建议

- **角色分工**：Web / Pwn / Reverse / Crypto / Misc 各有专攻，组队互补；
- **梯队建设**：高年级带低年级，形成传承（学院的竞赛传统就是这样滚起来的）；
- 关注校内实验室、战队招新通知，主动报名。

## 训练路径

1. 用 [CTF 平台与资源](../必学工具/CTF平台与资源.md) 的在线平台刷题；
2. 每道题写 Writeup（放 GitHub），积累题库与思路；
3. 从「跟赛」到「参赛」：先观摩线上赛，再组队正式参赛；
4. 赛后复盘：看高分队伍的题解，总结差距。

## 与课程结合

竞赛方向与课程高度对应：Crypto ↔ [密码学](../安全方向/密码学.md)，Pwn/Reverse ↔ [二进制安全与逆向](../安全方向/二进制安全与逆向.md)，Web ↔ [Web 安全](../安全方向/Web安全.md)，Misc ↔ [数字取证与舆情安全](../安全方向/数字取证.md)。**课上打基础、赛上练实战**，两条腿走路。

::: tip
  首次参赛目标不要定太高：进前十、解出一道题都是胜利。持续参赛、持续复盘，水平会在两三个学期内肉眼可见地提升。
:::
