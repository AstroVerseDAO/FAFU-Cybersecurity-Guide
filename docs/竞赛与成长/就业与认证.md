# 就业与认证

> 网安人才缺口巨大，岗位方向多元。本文汇总主流岗位与证书信息，具体招聘要求以企业发布为准。

## 岗位方向

| 方向 | 岗位举例 | 核心能力 |
| ---- | ---- | ---- |
| 攻防实战 | 渗透测试工程师、红队/蓝队 | 网络攻防、Web 安全、漏洞利用 |
| 安全运营 | 安全运维、安全运营中心（SOC）分析师、应急响应 | 系统加固、日志分析、事件处置 |
| 安全研发 | 安全产品研发、检测引擎开发 | 编程 + 安全知识（Web/二进制） |
| 安全研究 | 漏洞研究、威胁情报、逆向分析 | 二进制、逆向、恶意代码 |
| 合规咨询 | 等保测评、数据合规、安全咨询 | 法律法规 + 标准体系 |
| 新兴方向 | 云安全、AI 安全、车联网/IoT 安全 | 对应技术栈（见 [物联网与云安全](../安全方向/物联网与云安全.md) 等） |

## 常见认证

| 认证 | 说明 |
| ---- | ---- |
| CISP（注册信息安全专业人员） | 国内认可度高的从业认证，适合就业后考取 |
| NISP（国家信息安全水平考试） | 面向在校生的信息安全认证，分级考试 |
| OSCP | 国际知名渗透测试实战认证，含金量高、考取难度大 |
| CISSP | 资深安全从业者认证，偏管理/体系，需工作经验 |
| 等保测评师 / 云安全相关认证 | 对应具体岗位方向 |

::: note
  认证信息会随政策变化，请以官方机构最新公告为准；在校期间以技术实战为主，认证多在求职前后按需考取。
:::

## 简历与求职建议

- **用作品说话**：CTF 奖项、GitHub 安全项目（Writeup 仓库、自研工具）、实习经历，是网安简历的三大支柱；
- **实习前置**：大二暑期起争取安全公司/政企安全部门实习（实习僧、牛客、公司官网/公众号等渠道）；
- **校招节点**：秋招（大四上 9-11 月）与春招（大四下 3-5 月），安全大厂（奇安信、深信服、绿盟、天融信等）与综合大厂安全团队均可关注；
- 善用校园渠道：学院就业信息、校园招聘会、老师与学长内推。

## 长期视角

- 安全行业技术迭代快，**持续学习能力比当前水平更重要**；
- 深耕一个方向建立标签（如「Web 渗透」「二进制漏洞」），再横向扩展；
- 遵守职业道德与法律（见 [法律伦理与合规](../安全方向/法律伦理与合规.md)），口碑是安全人最宝贵的资产。
