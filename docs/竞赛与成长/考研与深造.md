# 考研与深造

> 网安是一个「重学历也重实战」的领域。本文整理考研/保研方向的信息与建议，具体政策以学校与目标院校当年通知为准。

## 保研（推免）

- **硬指标**：绩点排名 + 英语（四六级）+ 科研/竞赛经历；
- 学院「以赛促学」的竞赛成绩在保研评价中占重要权重——尽早参赛并积累奖项；
- 大三暑假关注目标院校的**夏令营**（网安相关学院/实验室）。

## 考研

- **考试科目**：通常为政治、英语、数学（一/二）+ 专业课（408 统考或院校自命题，如数据结构、计算机网络、操作系统等）；
- 网安考研热度高，建议提前一年启动数学与专业课；
- 目标院校可选：网安一级学科院校（如西电、北邮、川大、信工所等，以及双一流综合大学计算机/网安学院），结合自身定位选择。

## 保研/考研信息渠道

| 渠道 | 说明 |
| ---- | ---- |
| 目标院校研究生院官网 | 招生简章、复试方案（权威） |
| 目标实验室主页 | 导师方向与课题组信息 |
| 学长学姐 | 一手经验最重要，主动请教 |

## 出国深造（可选）

- 安全方向海外强校：美国（CMU、Berkeley、MIT 等）、欧洲部分高校；
- 需要早做准备：语言成绩、科研经历（进实验室发论文）、推荐信。

## 通用建议

- **科研经历**：大二起申请进入学院实验室（网络安全研究所方向），参与课题或发表论文，对保研、考研复试、出国都极有价值；
- 竞赛 + 科研 + 绩点，三条线尽量同时推进；
- 无论考研还是保研，**动手能力（CTF/项目）都是复试中的加分项**，别丢下。
