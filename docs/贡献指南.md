# 贡献指南

> 欢迎每一位 FAFU 网安学子、老师和行业朋友参与维护。你的补充会让后来者少走很多弯路。

## 你可以贡献什么

- **补充资源**：某门课更好的公开课、教材、实验平台；
- **纠错更新**：课程信息、链接失效、政策变化；
- **新增页面**：新的方向/课程页（按仓库根目录 [template.md](https://github.com/OpenFAFU/FAFU-Cybersecurity-Guide/blob/main/template.md) 模板）；
- **学习经验**：竞赛心得、实习/考研/就业经验帖。

## 方式一：提 Issue（最简单）

在仓库 [Issues](https://github.com/OpenFAFU/FAFU-Cybersecurity-Guide/issues) 页面：
- 描述你想补充/修改的内容；
- 附上资源链接或文字说明；
- 维护者会尽快处理。

## 方式二：提交 Pull Request

1. **Fork** 本仓库到你的账号；
2. 在 `docs/` 下按模板新增或修改页面，同步更新 `.vitepress/config.mts` 的 `sidebar`（如需新增页面）；
3. 本地预览（见下）；
4. 提交 PR，描述改动内容。

## 本地预览（可选）

```bash
npm install
npm run dev    # 浏览器打开 http://localhost:5173
```

## 内容规范

- 推荐资源优先选择**公开、知名、长期维护**的课程与平台；
- 涉及版权的资料只给链接与书名，不放盗版内容；
- 所有安全实验内容强调**授权与合规**（参考 [法律伦理与合规](安全方向/法律伦理与合规.md)）；
- 校内课程信息以教务最新安排为准，注明「以教务为准」。

## 行为准则

- 友善沟通，就事论事；
- 不发布任何攻击性、歧视性内容；
- 不发布未授权渗透、黑产相关的教程内容。
